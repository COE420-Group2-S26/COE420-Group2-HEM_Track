FR-01: Audit Trail: The system should log all user actions (create, update, delete) with user ID and timestamp for audit purposes
Source Scenario/Stakeholder: IT

FR-02: Maintenance Scheduling: The system should allow creation of preventive maintenance (PM) schedules based on frequency (daily, weekly, monthly, annual) or usage hours.
Source Scenario/Stakeholder: Maintenance Manager 

FR-03: Equipment Status Tracking: The system should display real-time status of each asset (Operational, Under Maintenance, Out of Service, Decommissioned)
Source Scenario/Stakeholder: Clinical Staff

FR-04: Automated Reminders/Alerts: The system should send automated notifications (email/SMS/dashboard) ahead of due maintenance or calibration dates.
Source Scenario/Stakeholder: Maintenance Team

FR-05: Equipment Registration: Users should be able to register new equipment with details such as asset ID, serial number, manufacturer, model, purchase date, location, and department.
Source Scenario/Stakeholder Inventory Manager
