# Integration and Consistency Check

## Data Flow Modeling

- The Context Diagram represents the proposed system correctly.
- External entities are consistent with UML Use Case actors.
- Level-0 DFD uses the same relevant external entities.
- Context Diagram and Level-0 DFD are balanced.
- Level-0 contains at least five meaningful processes.
- Level-0 contains at least two relevant data stores.
- Core Processes Matrix contains the same major processes as the Level-0 DFD.
- DFD processes are consistent with Functional Requirements and Use Cases.

## Project Scheduling

- WBS activities represent actual project work.
- Gantt Chart activities correspond to WBS activities.
- Task dependencies are logically defined.
- Time estimates are realistic and project-specific.
- Expected Times are correctly calculated.
- Network diagram reflects the WBS dependencies.
- ES, EF, LS, LF, and Slack calculations are correct.
- Critical Path is correctly identified.
- The Critical Path and project duration are verified using an appropriate scheduling/project-management tool.
